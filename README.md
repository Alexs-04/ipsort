# IPSORT

Actually, this project is the same as Solus, but with the difference that I created it specifically to test Java Swing;
it doesn't make much sense in itself, but it is what it is.

### Features

- Sorts IP addresses in ascending order
- Supports both IPv4
- Many more features will be added in the future, but for now, this is just a simple project to test Java Swing.

### Installation

1. Clone the repository:
   ```bash
    git clone https://github.com/Alexs-04/ipsort.git
    ```
2. Navigate to the project directory:
    ```bash
    cd ipsort
    ```
3. Compile the Java files:
    ```bash
    javac -d bin src/*.java
    ```
4. Run the application:
    ```bash
    java -cp bin Main
    ```

Or use the provided JAR file:

```bash
java -jar ipsort.jar
```

If you prefer, you can also run the application using Gradle:

```bash
./gradlew run
```
